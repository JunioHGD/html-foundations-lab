# Projetos

Esta seção reunirá projetos de integração ampla do **HTML Foundations Lab**. Diferentemente dos checkpoints, que consolidam um bloco específico, os projetos daqui podem combinar conhecimentos desenvolvidos em múltiplos blocos do currículo quando essa integração produzir uma evidência técnica relevante.

Cada projeto publicado terá pasta e `README.md` próprios, com apresentação do objetivo, contexto, competências integradas, estrutura construída e decisões técnicas pertinentes ao trabalho realizado.
