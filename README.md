# HTML Foundations Lab

![HTML](https://img.shields.io/badge/HTML-Foundations-E34F26?logo=html5&logoColor=white)

Laboratório para estudar e aplicar os **fundamentos essenciais de HTML**, com foco em estrutura, semântica, acessibilidade e integração com tecnologias web.
