# HTML-03 — Arquitetura semântica e acessibilidade nativa

[HTML Foundations Lab](../../README.md) › [Prática](../README.md) › HTML-03

Este bloco organiza grandes regiões da página por função documental e consolida HTML nativo como primeira camada de acessibilidade, deixando ARIA como complemento quando realmente necessário.

## Objetivo

Construir páginas cuja estrutura possua significado programaticamente perceptível e aproveite a acessibilidade fornecida pelo próprio HTML antes de recorrer a abstrações adicionais.
