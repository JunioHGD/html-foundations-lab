# HTML-06 — Integração e qualidade da marcação

[HTML Foundations Lab](../../README.md) › [Prática](../README.md) › HTML-06

Este bloco fecha o Lab relacionando HTML às camadas de apresentação e comportamento e estabelecendo critérios de conformidade, semântica, acessibilidade e evolução técnica da marcação.

## Objetivo

Relacionar HTML às demais camadas da plataforma Web e consolidar critérios para avaliar marcação profissional sem transformar o Lab em estudo de CSS ou JavaScript.

## Unidades

### [HTML-06.01 — Integração com CSS e JavaScript](./html-06.01-integracao-com-css-e-javascript/)

Compreender como o documento HTML expõe estrutura para apresentação e comportamento.

### [HTML-06.02 — Conformidade, semântica e evolução da linguagem](./html-06.02-conformidade-semantica-e-evolucao-da-linguagem/)

Desenvolver critérios para avaliar a qualidade da marcação e continuar aprendendo HTML de forma independente.

## Checkpoint

O checkpoint consolida a capacidade de integrar HTML a CSS e JavaScript sem confundir responsabilidades e de avaliar marcação por sintaxe, estrutura, semântica, acessibilidade e conformidade, não apenas pela renderização.
