# HTML-05.02 — Submissão e fronteira com o servidor

A unidade acompanha os dados do formulário até a submissão, explicando destino, método, pares nome–valor e o ponto em que termina a responsabilidade do HTML e começa o processamento no servidor.

## Objetivo

Compreender o ciclo de submissão de dados até o limite da responsabilidade do HTML.

## Conceitos fundamentais

1. `form` como contexto de submissão;
2. destino com `action`;
3. método de submissão;
4. `GET` e `POST` no nível pertinente ao formulário HTML;
5. pares nome–valor dos controles;
6. controles participantes da submissão;
7. botões de submissão;
8. diferença entre estrutura e coleta em HTML e processamento no servidor;
9. ausência de garantia de segurança apenas pela marcação ou validação do navegador.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Submissão e fronteira com o servidor**.
