# HTML-05.03 — Assistência ao preenchimento e validação declarativa

[HTML Foundations Lab](../../../README.md) › [Prática](../../README.md) › [HTML-05 — Formulários e controles nativos](../README.md) › HTML-05.03

A unidade utiliza recursos declarativos e comportamento nativo do navegador para orientar o preenchimento e validar dados no nível de experiência do usuário, sem tratar essa validação como mecanismo de segurança.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Utilizar recursos nativos do HTML para ajudar o usuário a fornecer dados adequados.

## Conceitos fundamentais

1. escolha do tipo de entrada conforme o dado esperado;
2. campos obrigatórios;
3. restrições declarativas de comprimento, intervalo e formato quando pertinentes;
4. `autocomplete`;
5. instruções associadas aos campos;
6. Constraint Validation do navegador;
7. estados de validade;
8. mensagens de erro compreensíveis;
9. diferença entre validação para experiência do usuário e validação para segurança;
10. necessidade de validação independente no servidor.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Assistência ao preenchimento e validação declarativa**.
