# HTML-05 — Formulários e controles nativos

[HTML Foundations Lab](../../README.md) › [Prática](../README.md) › HTML-05

Este bloco constrói formulários a partir de controles nativos, nomes, valores, rotulagem, submissão e validação declarativa, mantendo explícita a fronteira entre HTML, experiência do usuário e servidor.

## Objetivo

Construir o modelo completo de formulários como mecanismo para coletar, identificar, organizar, restringir e submeter dados, sem confundir HTML com seu processamento no servidor.

## Unidades

### [HTML-05.01 — Controles, nomes, valores e rotulagem](./html-05.01-controles-nomes-valores-e-rotulagem/)

Compreender como os controles representam campos de dados utilizáveis e acessíveis.

### [HTML-05.02 — Submissão e fronteira com o servidor](./html-05.02-submissao-e-fronteira-com-o-servidor/)

Compreender o ciclo de submissão de dados até o limite da responsabilidade do HTML.

### [HTML-05.03 — Assistência ao preenchimento e validação declarativa](./html-05.03-assistencia-ao-preenchimento-e-validacao-declarativa/)

Utilizar recursos nativos do HTML para ajudar o usuário a fornecer dados adequados.

O checkpoint consolida a construção de formulários semanticamente estruturados e acessíveis, verificando controles, rotulagem, pares nome–valor, submissão, validação nativa e limites da responsabilidade do HTML.
