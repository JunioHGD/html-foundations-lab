# Prática e Evidências

Esta seção organiza a documentação e as evidências selecionadas do Lab segundo a mesma progressão definida pelo currículo. Cada bloco apresenta suas unidades e encerra com um checkpoint de validação cumulativa.

## Blocos

### HTML-01 — Linguagem, documento e processamento

Este bloco estabelece o modelo fundamental de HTML como linguagem de marcação semântica processada pelo navegador, relacionando código-fonte, estrutura documental, parsing, DOM e conformidade.

[Explorar bloco →](./html-01-linguagem-documento-e-processamento/)

### HTML-02 — Conteúdo semântico e hipertexto

Este bloco desloca o foco da sintaxe para o significado do conteúdo, desenvolvendo hierarquia documental e hipertexto como mecanismos centrais de organização e navegação.

[Explorar bloco →](./html-02-conteudo-semantico-e-hipertexto/)

### HTML-03 — Arquitetura semântica e acessibilidade nativa

Este bloco organiza grandes regiões da página por função documental e consolida HTML nativo como primeira camada de acessibilidade, deixando ARIA como complemento quando realmente necessário.

[Explorar bloco →](./html-03-arquitetura-semantica-e-acessibilidade-nativa/)

### HTML-04 — Conteúdo visual e dados estruturados

Este bloco trabalha dois modelos semânticos específicos: imagens tratadas conforme sua finalidade comunicativa e tabelas usadas exclusivamente para representar relações genuinamente tabulares.

[Explorar bloco →](./html-04-conteudo-visual-e-dados-estruturados/)

### HTML-05 — Formulários e controles nativos

Este bloco constrói formulários a partir de controles nativos, nomes, valores, rotulagem, submissão e validação declarativa, mantendo explícita a fronteira entre HTML, experiência do usuário e servidor.

[Explorar bloco →](./html-05-formularios-e-controles-nativos/)

### HTML-06 — Integração e qualidade da marcação

Este bloco fecha o Lab relacionando HTML às camadas de apresentação e comportamento e estabelecendo critérios de conformidade, semântica, acessibilidade e evolução técnica da marcação.

[Explorar bloco →](./html-06-integracao-e-qualidade-da-marcacao/)
