# HTML-04 — Conteúdo visual e dados estruturados

[HTML Foundations Lab](../../README.md) › [Prática](../README.md) › HTML-04

Este bloco trabalha dois modelos semânticos específicos: imagens tratadas conforme sua finalidade comunicativa e tabelas usadas exclusivamente para representar relações genuinamente tabulares.

## Objetivo

Dominar dois mecanismos com modelos semânticos próprios: incorporação acessível de imagens e representação de dados tabulares.

### [HTML-04.02 — Modelo de dados tabulares](./html-04.02-modelo-de-dados-tabulares/)

Representar relações genuinamente tabulares de maneira compreensível visual e programaticamente.
