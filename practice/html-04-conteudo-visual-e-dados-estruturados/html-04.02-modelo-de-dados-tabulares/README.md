# HTML-04.02 — Modelo de dados tabulares

[HTML Foundations Lab](../../../README.md) › [Prática](../../README.md) › [HTML-04 — Conteúdo visual e dados estruturados](../README.md) › HTML-04.02

A unidade constrói o modelo semântico de tabelas para dados, relacionando células, cabeçalhos, escopo e legenda sem utilizar estruturas tabulares como mecanismo de layout.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Representar relações genuinamente tabulares de maneira compreensível visual e programaticamente.

## Conceitos fundamentais

1. tabela como representação de dados, não como mecanismo de layout;
2. linhas, colunas e células;
3. células de dados;
4. células de cabeçalho;
5. relações entre dados e cabeçalhos;
6. cabeçalhos de linha e de coluna;
7. `scope` em estruturas simples;
8. legenda da tabela com `caption`;
9. estrutura semântica necessária à compreensão por tecnologias assistivas.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Modelo de dados tabulares**.
